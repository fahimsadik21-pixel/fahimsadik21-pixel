### 👨‍💻 About Me

I am a final-year Computer Science & Engineering undergraduate (8th Semester) at **Daffodil International University (DIU)** with a CGPA of **3.60 / 4.00**.

My work is centered around **Healthcare AI**, **Explainable Machine Learning (XAI)**, and **Full-Stack Intelligent Systems**. I focus on designing leakage-resistant, clinically reliable machine learning pipelines and deploying them into responsive, end-to-end web applications and IoT solutions.
